Precision Hierarchy & Custom Applet Manager for Windows Control Panel

Control Panel Management Preferences (CplMgrPref.exe + EliteCplMgr.Engine.dll) enumerates, edits, categorizes, tests, backs up, and registers custom applets directly in the 64-bit Windows Control Panel NameSpace and CLSID hives without PowerShell wrapper overhead.

64-Bit Registry Engine ELITECPLMGR.ENGINE

  • Reads and writes HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\ControlPanel\NameSpace and HKLM\SOFTWARE\Classes\CLSID via RegistryView.Registry64.
  • Assigns multi-category Control Panel placement (AllItems, AppearancePersonalization, HardwareSound, NetworkInternet, SystemSecurity, Programs, etc.).
  • Tags custom applets with CreatedByCustomCplTool and writes direct shell commands without wrapper scripts.

Safety, Rollback & Testing v1.2.7.0

  • History Nexus & Revert: Supports Undo Last and Revert Icon rollback using structured history state.
  • Import / Export All: Back up and migrate full custom Control Panel definitions in one click.
  • Live Test Item: Launch and verify configured target paths and custom .ico previews before deploying changes.
